Each identifier is tuned on its own scale — a face embedding's cosine scores sit around 0.36 and a generic appearance embedding's above 0.80, so these numbers are not comparable with each other. Preview replays the recorded scores of past matches at a candidate value; it is an estimate, not a re-run of the resolver, and it never re-scores plate matches. Saving writes the config file — ingest picks it up on restart, because siteloom serve and siteloom run are separate processes. Past matches keep the score they were made at.
