No iCal feed is configured

This list is empty because nothing feeds it, not because nobody is staying. With no calendar, guest_window is never stamped and every arrival looks like an unknown vehicle.

Set guests.ical in the site config to the booking calendar's URL or a local .ics path, then run siteloom sync-bookings. Until then, bookings added above are the only ones this site has.
