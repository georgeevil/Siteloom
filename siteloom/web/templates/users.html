No accounts — the console is in open single-operator mode

Authentication turns on when the first account exists. Until then every page is reachable without signing in and mutations are audited as (open). This is the mode the PoC started in, and nothing on this screen has anything to act on yet.

Create the first account on the host with siteloom users add <name> --role admin. Make it an admin: the first account is the only one that can create the rest, and a console whose only account is a viewer is recovered from a shell.

Accounts are created from the shell, by design

There is no "Add operator" button. Creating the first account is what switches authentication on, and a web-creatable account is a web-creatable admin — so enrolment stays where a shell login is already the credential.

siteloom users add <name> --role {{ roles | join('|') }} · siteloom users passwd <name> · siteloom users role <name> <role> · siteloom users enable <name>
